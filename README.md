# Hack The Box Writeups

A collection of writeups for Hack The Box challenges I've solved.

> **Status:** Work in progress — I recently started, as I just found out that I like the security area.

## About

Each writeup walks through the full process for a given challenge: reconnaissance, enumeration, exploitation, and remediation. Where relevant, findings are mapped to industry standards (CWE, CAPEC, OWASP ASVS) and linked to real-world CVEs with similar root causes.

## Structure

Each writeup generally follows this format:

1. **Resumen** — summary of the challenge and approach
2. **Reconocimiento** — initial recon and attack surface mapping
3. **Enumeración y Análisis** — vulnerability identification
4. **Explotación** — step-by-step exploitation
5. **Trazabilidad y Ciclo de Desarrollo** — root cause, CWE/CAPEC/CVE mapping
6. **Remediación** — mitigation and best practices
7. **Lecciones aprendidas** — takeaways
